# R.I.S.E CRM Frontend

Web App for R.I.S.E (Retention Intelligence on Sales Engagement), a CRM that predicts customer churn and helps teams act on it.

## Stack
React, Framer Motion, Recharts. Deployed on Vercel.

## Getting started
1. `npm install`
2. Copy `.env.example` to `.env` and set the backend API URL
3. `npm run dev`
